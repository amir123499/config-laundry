قبل از شروع

  • کلاینت: PattNG برای اندروید و PattN برای ویندوز، لینوکس و مک. از github.com/patterniha/PattNG/releases دانلود کن. README پروژه می‌گوید cipherSuites و fingerprint unsafe در این نسخه‌ها اضافه شده‌اند.
  • ZedSecure هم کلاینت خوبی است، ولی مستنداتش فیلدهای finalMask و cipherSuites را نگفته. اگر روش‌ها روی آن جواب نداد، با PattNG امتحان کن.
  • فایروال: مخابرات، شاتل و همراه اول زیر فایروال همراه اول هستند. ایرانسل، پیشگامان و مبین‌نت زیر فایروال ایرانسل. بعضی جاها سیم‌کارت و فایروال فرق دارند. اگر مطمئن نیستی، هر دو روش را امتحان کن.
  • وضعیت فایروال‌ها هر چند روز عوض می‌شود. آخرین خبر را از کانال patterniha بخوان.

همراه اول · ECH

  1. در تب «ساخت کانفیگ» روش ECH را انتخاب کن. آی‌پی تمیز اختیاری است؛ اگر دادی، مثل 188.114.97.6 استفاده می‌شود.
  2. لینک‌ها را از «همه در یک کادر» کپی کن و در PattNG از Import from clipboard وارد کن.
  3. روی هر کانفیگ مداد را بزن و چک کن: finalMask خالی، cipherSuites خالی، fingerprint = chrome، echConfigList = cloudflare-ech.com+h2c://1.1.1.1/dns-query.
  4. طبق پیام جدید Patt، برای گرفتن کلید ECH بدون plain DNS این outbound را هم یک‌بار به تنظیمات PattNG/PattN اضافه کن (از نسخه PattNG ‏P67‏ و PattN ‏P34‏ به بعد):
  5. ذخیره کن و وصل شو.
۲

همراه اول · IPv6

  1. روش IPv6 را انتخاب کن و یک آدرس IPv6 بده، مثل 2a06:98c1:3121::7. آدرس IPv4 قبول نمی‌شود.
  2. اگر دامنه‌ات فیلتر نیست، تیک «دامنه‌ام فیلتر است» را نزن. اگر فیلتر است، تیک را بزن تا finalMask = tlshello-0-len اضافه شود.
  3. داخل PattNG چک کن: echConfigList خالی، cipherSuites خالی، fingerprint = chrome.
  4. اینترنت خودت باید IPv6 داشته باشد. اگر نداری، این روش برایت کار نمی‌کند.
۳

همراه اول · WARP با IPv6 (دستی)

  1. داخل PattNG برو به add aether.
  2. Protocol را روی wireguard یا warp-in-warp بگذار.
  3. نوع آی‌پی را IPv6 انتخاب کن.
  4. Scan بزن. بعد از پیدا شدن آی‌پی، یک اسم انتخاب کن و Save کن.
طبق Patt روی فایروال همراه اول، UDP کلودفلر بسته شده. پس WireGuard و masque-h3 بدون IPv6 کار نمی‌کنند.
۴

ایرانسل · Fragment + Fingerprint

  1. روش Fragment را انتخاب کن و یک آی‌پی سالم (مثل 188.114.97.6) بده.
  2. لینک‌ها را وارد PattNG کن و چک کن: echConfigList خالی، finalMask = tlshello-0-len، cipherSuites = semi-python، fingerprint = unsafe.
  3. ALPN: برای ws مقدار http/1.1 و برای XHTTP مقدار h2,http/1.1. ابزار این را خودکار می‌گذارد، ولی داخل اپ هم چک کن.
۵

ایرانسل · WARP (دستی)

  1. مراحل «همراه اول · WARP با IPv6» را انجام بده.
  2. فرقش این است که روی ایرانسل نوع آی‌پی می‌تواند IPv4 یا IPv6 باشد.
۶

ایرانسل · MASQUE/H2 (دستی)

  1. داخل PattNG برو به add aether.
  2. Protocol را روی MASQUE-HTTP/2 بگذار.
  3. fingerprint = semi-python و finalMask = tlshello-0-len.
  4. Scan بزن، بعد از پیدا شدن آی‌پی یک اسم انتخاب کن و Save کن.
۷

دامنه‌های railway.app و دامنه‌های رایگان

  1. ECH: مقدار echConfigList = cloudflare-ech.com+h2c://1.1.1.1/dns-query. همان روش ECH همین ابزار.
  2. finalMask + fingerprint: مقدارهای این روش در پست کانال SPiDER_VPN1 به شماره ۱۰۸۵ آمده (t.me/SPiDER_VPN1/1085). این پست را من باز نکردم؛ مقدارهایش را با مقدارهای Fragment همین ابزار مقایسه کن.
  3. SNI spoof با fake sni = auth.vercel.com و آی‌پی = 188.114.96.7: این با تغییر لینک انجام نمی‌شود و نیاز به هستهٔ SNISPF دارد، پس داخل این ابزار نیست. برای پیدا کردن جفت SNI و آی‌پی سالم از NaxonM/SNI-Finder استفاده کن. این اسکنر برای ویندوز و لینوکس است؛ اسمش را توی گوگل یا گیت‌هاب بزن.
۸

پروکسی IP (روش جدید همین ابزار)

  1. روش پروکسی IP را انتخاب کن و یک پروکسی IP بده، مثل ProxyIP.US.CMLiussss.net. لیست زنده که هر ۶ ساعت اسکن می‌شود: amir123499.github.io/proxyip-board
  2. ابزار به انتهای path هر کانفیگ &proxyip=... اضافه می‌کند؛ اگر path علامت سؤال نداشت، با ?proxyip= شروع می‌شود. مثلاً: /?ed=2048&proxyip=ProxyIP.US.CMLiussss.net
  3. فقط همین کانفیگ‌ها از پروکسی IP استفاده می‌کنند و بقیهٔ تنظیمات دست‌نخورده می‌ماند.
  4. اگر جواب نداد، همان کانفیگ‌ها را با روش «عادی» دوباره بساز تا به حالت قبل برگردند.
طبق سورس edgetunnel، ورکر هم ?proxyip= در کوئری و هم /proxyip= و /pyip= در مسیر را می‌فهمد.
!

چند نکتهٔ مهم

  • اگر لینک‌ها در اپ وارد نشدند، مقدارها را دستی بگذار. ابزار نمی‌داند اپ کدام پارامترها را از لینک می‌خواند.
  • اگر کانفیگ با یک روش روی مخابرات جواب داد ولی روی ایرانسل نه (یا برعکس)، طبیعی است. فایروال‌ها فرق دارند. کانفیگ‌ها را جدا نگه دار و بر اساس اینترنتی که الان داری جابه‌جا کن.
  • وقتی کانفیگ‌های زیاد داری، اول یک نمونه را امتحان کن و بعد بقیه را وارد کن.
