# 🧺 خشکشویی کانفیگ — Config Laundry

ابزار **کاملاً آفلاین** برای تمیز و فیکس کردن کانفیگ‌های VLESS / Trojan / Shadowsocks،
مخصوص فایروال‌های ایران (همراه اول و ایرانسل).

**نسخه:** v14 · **بدون حتی یک ریکوئست شبکه** — فونت وزیرمتن هم داخل خود فایل جاسازی شده.

## 🚀 استفاده

https://amir123499.github.io/config-laundry/

فایل را دانلود و باز کن، یا از لینک بالا استفاده کن. نیازی به نصب نیست.

## 🛠️ روش‌های فیکس (۵ روش)

| روش | برای |
|---|---|
| **Fragment** | فایروال ایرانسل |
| **ECH** | فایروال همراه اول |
| **IPv6** | فایروال همراه اول (با تیک «دامنه‌ام فیلتر است» که `finalMask` اضافه می‌کند) |
| **عادی** | بدون تغییر روش — فقط تمیزکاری |
| **پروکسی IP** | تغییر مسیر خروجی با `proxyip=` در path (فقط WS-like؛ بقیه را هشدار می‌دهد و رد می‌شود، تگ‌های قدیمی `-PX` را پاک می‌کند) |

## ✨ همه قابلیت‌ها

- 🎨 **سه دیزاین کاملاً متفاوت** قابل تعویض از هدر: Aurora (شفق) / Brutal / Terminal — از نو ساخته شده، نه فقط تعویض رنگ
- 🌈 **شش رنگ اکشن** قابل ذخیره (پیش‌فرض: teal)
- 🔀 **ترکیب دو روش** به صورت مساوی ۵۰/۵۰، با امکان جابه‌جا کردن ترتیب
- 🏷️ **نام‌گذاری خودکار:** برچسب روش به آخر اسم، اضافه کردن آی‌پی به اسم، پسوند دلخواه جداگانه برای هر روش
- 🌐 **آی‌پی تمیز:** پخش چرخشی بین کانفیگ‌ها، همه با آی‌پی اول، یا هر کانفیگ با همه آی‌پی‌ها
- 📋 **تب راهنما:** آموزش روش‌ها، اتصال و پینگ گرفتن، اشتراک PattNG، راهنمای قدم‌به‌قدم همراه اول (ECH / IPv6 / WARP) و ایرانسل (Fragment / WARP / MASQUE)، دامنه‌های railway.app، و روش پروکسی IP
- 🔗 **تب گیست:** تمیزکننده لینک گیست — هش را از لینک raw حذف می‌کند
- 🧠 انتخاب روش **هر بار از نو** انجام می‌شود (ذخیره نمی‌شود)؛ روش انتخاب‌شده تیک ✓ می‌گیرد
- 💾 تنظیمات (دیزاین، رنگ) در مرورگر ذخیره می‌شود
- 📴 **۱۰۰٪ آفلاین:** هیچ درخواستی به اینترنت نمی‌فرستد
